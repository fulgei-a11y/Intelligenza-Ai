Rembrandt porta il fotoritocco con l'AI gratis e locale su computer

Aggiornato alle 17:07

La novità più interessante di oggi è Rembrandt, un'alternativa gratuita ad Adobe Lightroom che permette di ritoccare le fotografie sul computer semplicemente descrivendo a parole le modifiche desiderate. Trovi anche diversi strumenti utili per organizzare i file sul Mac ed elaborare contenuti visivi.

Rembrandt

È un software gratuito per il fotoritocco che applica modifiche alle fotografie interpretando comandi in testo semplice, come rendere l'immagine più calda o più luminosa, senza alterare i file originali.

Come iniziare

  1. Scarica e installa l'applicazione per Mac, Windows o Linux dal sito ufficiale del progetto
  2. Seleziona la cartella del tuo computer che contiene le foto da modificare
  3. Scrivi a parole la modifica desiderata o usa i comandi visivi per regolare luci, colori e sfondi
